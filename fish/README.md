# My Fish shell dotfiles, Qtile (main) and Niri (sub) on CachyOS. 

I'm basically following the CachyOS configuration. However, I prefer `lsd` to `eza` for the `ls` command. Therefore, although it's a bit unconventional, I've established the following rules:

- When executing `ls`, use `eza`
- `la`, which I use primarily, executes `lsd`

I don't have the skills to build an environment from scratch without loading the default CachyOS configuration, `source /usr/share/cachyos-fish-config/cachyos-config.fish`.


This set of dot files is shared between two environments:

1. **`chandanna`**: Qtile (main), Niri (sub) on CachyOS
2. **`bacstual`**: Qtile, which I built myself based on Xfce4 on EndeavourOS
