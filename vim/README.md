# My Vim's configuration.

- For heavy coding, I use Code/OSS
- For light tasks like editing configuration files, I use LazyVim

That's how I differentiate between them.

However, lately I've started to wonder if even LazyVim is too heavy, and I've started using Vim more often again.
The reason I stopped actively using Vim is because I create configuration files directly in my home directory.

My constraint on Vim is that I only do the bare minimum of settings, enough to be contained within `~/.vimrc`.
I can only do the bare minimum settings, such as syntax highlighting, but I've compromised on that.
